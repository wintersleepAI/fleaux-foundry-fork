# Fléaux!

Adapatation du jeux de rôle **Fléaux!** sur **Foundry VTT**.

---
> **Important** : Le système fonctionne seulement sur les navigateurs **Chrome** et **Edge**. Les tests sur **Firefox** ne sont pas concluant.
---
